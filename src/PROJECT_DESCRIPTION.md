# Описание приложения

Данное приложение представляет собой серверную часть системы управления парковкой, реализованную как REST API с использованием спецификации [OpenAPI (Swagger)](https://swagger.io/specification/). Приложение предназначено для автоматизации процессов въезда и выезда автомобилей на парковку, хранения и получения информации о парковочных сессиях, а также для генерации различных отчётов по использованию парковки.

## Основные возможности

- **Регистрация въезда и выезда автомобилей на парковку**  
  Приложение фиксирует факты въезда и выезда транспортных средств, хранит соответствующую информацию и возвращает подтверждение о совершённых действиях.

- **Получение информации о сессиях парковки**  
  Можно получить список всех сессий с пагинацией, а также детальную информацию по конкретной сессии по её идентификатору.

- **Генерация отчётов**  
  Формируются отчёты по парковочным сессиям за указанный временной интервал.

- **Версионирование API**  
  Для обеспечения обратной совместимости реализованы две версии API (v1 и v2).

## Входные и выходные данные

### Входные данные

Приложение принимает следующие данные в виде JSON-объектов через HTTP-запросы:

- **Данные о въезде (`EnterRequestDto`, `EnterRequestDtoV2`)**
    - Например: номер автомобиля, время въезда, дополнительная информация (по версии).
- **Данные о выезде (`ExitRequestDto`, `ExitRequestDtoV2`)**
    - Например: номер автомобиля, время выезда, идентификатор сессии.
- **Параметры пагинации (`PageableDto`)**
    - Например: номер страницы, размер страницы.
- **Параметры отчёта**
    - Даты начала и конца интересующего интервала.

### Выходные данные

В ответ на запросы приложение возвращает структурированные JSON-объекты:

- **Информация о результате въезда (`EnterResponseDto`)**
    - Например: идентификатор сессии, подтверждение въезда, дополнительные сведения.
- **Информация о результате выезда (`ExitResponseDto`)**
    - Например: идентификатор сессии, подтверждение выезда.
- **Список парковочных сессий (`List<ParkRecordResponseDto>`)**
    - Информация о нескольких сессиях, включая идентификаторы, номера авто, время въезда/выезда и т.д.
- **Детали сессии (`ParkRecordResponseDto`)**
    - Подробная информация о конкретной парковочной сессии.
- **Отчёты (`ReportDto`, `ReportDtoV2`)**
    - Сводная информация об использовании парковки за выбранный период: общее количество сессий, статистика и прочее.

## Кратко по назначению

Это приложение — backend для парковочного комплекса, который:

- Позволяет интегрировать интерфейсы пользователей (мобильные приложения или сайты) с парковкой.
- Служит ядром для хранения, поиска и анализа информации о парковочных событиях.
- Поддерживает формирование и выгрузку отчётов по парковке для администраторов и операторов.
